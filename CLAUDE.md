# Adriva Rules

This is production software.

Never use Bootstrap.

Never use Material UI.

Never use inline styles unless necessary.

Always use:

- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- shadcn/ui

Design inspiration:

- Apple
- Linear
- Vercel
- Stripe
- Raycast

UI must feel premium.

Animations should be subtle.

Never over animate.

Always create reusable components.

Always think mobile first.

Never hardcode colors.

Never hardcode spacing.

Never duplicate components.

Write clean code.

Follow feature-first architecture.

If unsure, ask before making architectural changes.
